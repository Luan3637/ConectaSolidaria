# ConectaSolidaria
O ConectaSolidária é uma plataforma web desenvolvida para ajudar ONGs a divulgar projetos sociais, captar doações e atrair voluntários. O site possui três páginas principais: inicial, projetos sociais e cadastro. Utiliza HTML5, CSS3 e JavaScript, aplicando conceitos de responsividade, acessibilidade e interatividade estudados na disciplina.
